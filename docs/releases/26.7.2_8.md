# OPNcell 26.7.2_8 candidate

Includes the runtime/installer changes described in revision 7, replacing its
unsafe driver dependency choice. Revision 7 was withdrawn before publication.

The subscriber read helper uses the existing OPNsense Python 3.13 interpreter in
isolated (`-S`) mode, with unmodified PyMongo 4.18.2 source modules under the private
`/usr/local/share/opncell-pymongo` directory. The 292 KB `opncell-pymongo` package
depends only on `python313>=3.13`. It owns no shared CLI files or site packages.
Optional C extensions and DNS/SRV/TLS extras are not installed. This helper connects
to the existing local loopback database; remote/authenticated access is separate work.

Validation: FreeBSD stage QA and plist checks pass for both packages. The client
imports and round-trips BSON types on Python 3.13 with all site packages disabled.
30 Python tests, six sorting checks, and three MongoDB lifecycle checks pass. An
isolated installed-package fixture containing OPNsense/Python 3.13 dependencies
previews exactly one added client and one plugin upgrade, with zero removals.
The real appliance preview and UI latency/sorting acceptance are still required.

Python 3.13 is a platform prerequisite supplied by OPNsense, not a core interpreter
replacement distributed by this repository. The existing Python 3.12 provisioning
tools remain unchanged. A topology reconfiguration never restarts running MongoDB.

Use the upgrade-only test repository to check the existing appliance first. It
contains only the plugin and private client, intentionally preventing a solver from
substituting another Python dependency tree. The full release repository is assembled
separately for supported OPNsense 26.7 installations.
