# 26.7.2_20 candidate

Restores Diagnostics daemon submenu entries and direct log pages using OPNsense's dynamic menu hook. Only running managed daemons are listed. Fixes FreeBSD process column parsing. When no daemons are running, Diagnostics shows a short empty-state message. Existing log layout, row-count All and timeframe All remain unchanged.

Subscriber List offers Export subscribers. Bulk add offers a header-only CSV template beside the heading “Below is a template for what the expected import file SHOULD look like:”. The example is literal comma-separated text with the same 16 columns as the template and export.

CSV columns include IMSI, Ki, OPc/OP, AMF, MSISDN, profiles, UE-AMBR values and units, subscriber status, operator-determined barring, default slice, session addresses and PCC rules. JSON columns use normal CSV quoting. Leading zeros remain strings in the file; spreadsheet users should import identity/key columns as text.

The optional profiles column is a JSON list of SST[:SD]/APN selectors. Bulk import resolves each selector to one existing profile and reports missing or ambiguous matches by record. Without this column, or when blank, it uses the selected profiles. Profile QoS, session type, slice and session bandwidth settings come from those existing profiles; this is a provisioning CSV, not a database backup. Runtime authentication counters, object IDs and registration state are omitted. Existing subscribers are reported as duplicates rather than overwritten.

Validation: 60 Python tests; PHP CSV quoting/template, bulk field/profile/error handling, active menu/page routing, date/paging, topology lifecycle and subscriber sorting checks; JavaScript log-filter tests; FreeBSD stage, plist and package checks. Appliance presentation and live export/import acceptance remain pending. This candidate has not replaced the public revision 18 catalogs.
