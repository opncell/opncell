# 26.7.2_9 candidate

Includes revision 8 and these Cellular Diagnostics changes:

- Displays the viewer log path beneath Search, alongside the timeframe controls.
- Clears direct daemon logs by truncating the existing files, preserving open writers and file permissions. Dated history read by the viewer is also cleared. No service restart is requested.
- Reports clear failures instead of unconditionally declaring success.
- Includes the selected timeframe, search text, and severity in downloads.

Local validation: 33 Python tests, PHP syntax checks, JavaScript syntax check, and whitespace checks passed. The log test holds a writer open across Clear and verifies that subsequent records appear in the same file. Appliance UI placement, download filtering, and MME logging after Clear require acceptance testing.

The profile Subscribed users count sorting issue remains outstanding; this release does not claim to fix it. MongoDB Diagnostics still uses the legacy /var/log/opncell/mongod.log viewer source rather than /var/db/mongodb/mongod.log; the displayed path identifies the viewer source.

This is a private upgrade candidate. No public repository activation is included.
