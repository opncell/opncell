# OPNcell 26.7.2_7 candidate

**Withdrawn, never published.** The appliance preview exposed conflicting Python
3.12 CLI packages that would remove OPNsense Python 3.13 components. Do not install
this candidate. Revision 8 isolates the client and retains the OPNsense environment.

## Changes

- Subscriber List sorts IMSI/profile values before pagination. IMSIs stay strings,
  preserving leading zeros and 16-digit identities. Profiles use case-insensitive
  natural ordering and IMSI tie breaks.
- Subscriber and profile list reads use PyMongo directly, projecting only IMSI and
  session names. Reads no longer start mongosh twice or create indexes. Profile
  List no longer performs its configuration search twice or appends duplicate rows
  outside the JSON `rows` field.
- A running MongoDB is not stopped, restarted, or reloaded on topology Apply.
  Legacy start endpoints use the packaged service and a shared start lock;
  they cannot kill mongod or create an alternate data directory.
- Apply verifies effective boot settings with `service ... rcvar`, including
  `/etc/rc.conf.d`. Global `sysrc -a` output alone does not show effective settings.
- The package carries 22 configuration defaults, including all four freeDiameter
  files, and three installation/migration helpers. No private TLS keys are shipped.
- The installer preserves legacy configurations before package removal, corrects
  paths, checks TLS/extension files, and verifies restored records/types/indexes.
- MongoDB dependency is at least 8.0.34_3. That build passed startup, 14-record
  migration comparison, reboot, RAN registration and data sessions on the Atom
  C3858 without AVX. This does not certify the new plugin UI changes.

## Validation status

30 Python tests, six PHP sorting/pagination checks, and three topology/MongoDB lifecycle checks pass. PHP lint and FreeBSD
staging/file-list QA pass. Appliance list/search timing, sorting, topology Apply,
and the full migration/fresh installation workflow still require acceptance.

The candidate contains the official PyMongo dependency closure. Existing
mongosh-based provisioning writes remain available. Python 3.12.15 retains the
recorded poplib/imaplib vulnerability findings; see `package-audit.txt`.

## Appliance acceptance

Use a temporary file repository and preview the os-cellular upgrade. It must not
downgrade or replace OPNsense, MongoDB or Open5GS on the validated host. New driver
dependencies are expected. No MongoDB restart is required.

Confirm subscriber counts, ascending/descending ordering across pages, fast
profile search and correct counts. Check MongoDB's PID stays unchanged across
topology Apply. Check selected and unused daemon settings through `service NAME
rcvar`. Keep the previous release and all configuration/database/boot backups.

See [the migration installer procedure](../mongodb-installation-migration.md).
