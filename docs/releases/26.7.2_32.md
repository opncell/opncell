# OPNcell 26.7.2_32

Published 2026-11-11. This release consolidates revisions 28–32 on top of the revision-27 freeze.

## Changes since revision 27

- Preserve existing MongoDB 8.0 database paths, service flags and subscriber provisioning during installer upgrades. Create private configuration/package recovery copies and a cold database backup when replacing the MongoDB binary. Add plan-only mode and an automatically allocated private recovery directory.
- Retain CPU-aware installation with validated MongoDB 8.0.34_3 NOAVX and 8.0.34_1 AVX2 artifacts. The corrected portable binary was tested on hardware without AVX. A package option label alone is not a compatibility guarantee.
- Preserve the prepared MongoDB 5-to-8 logical migration path; old MongoDB data files are not opened directly by MongoDB 8.
- Normalize stock local MongoDB URIs to IPv4, preserving custom URIs.
- Persist the SCTP socket-buffer override through reboot using real tunable records rather than virtual placeholders.
- Add sortable service listening ports beside the bind address.
- Store Hnet public exports persistently and rebuild missing exports from retained private keys. Correct Profile B compressed public HEX generation.
- Add authenticated, passphrase-encrypted Hnet export/import bundles with previews, conflict checks, private recovery backups, deletion and transactional UDM updates. Restart UDM only when already running and necessary. See [Hnet management](../../packaging/HNET-KEY-MANAGEMENT.md).
- Restore exact diagnostic record totals and footer translations. Preserve JSON pagination/search/severity fields when applying the hourly filter, and exclude the older boundary record yielded by the platform matcher. Row count and timeframe remain independent.

Earlier subscriber-schema, CSV, topology, freeDiameter, log-path and rotation fixes remain included through the revision-27 baseline and cumulative port patches.

## Validation

- 89 automated tests passed, plus the JSON/form hourly-request regression check.
- FreeBSD stage and packing-list checks passed; package dependencies and executable helper permissions were checked.
- Staging verified 116 HTTP file hashes. After activation, both public CPU routes returned the expected revision-32 plugin hash and the FreeBSD 14 metadata remained available.
- Three existing appliances completed repository upgrades. The built-in OPNsense firmware package action fetched revision 32 and upgraded revision 31 successfully on one appliance.
- That GUI upgrade preserved all 12 database/cellular process IDs, Hnet key hashes and UDM configuration; installed-package integrity and database access passed.
- A subsequent OPNsense 26.7.9 upgrade and reboot brought back all 11 selected 5G SA daemons and MongoDB, verified boot settings, AMF/UPF listeners, and unchanged Hnet/UDM configuration.
- Earlier acceptance included a clean-clone installation/reboot and a logical MongoDB 5-to-8 migration preserving 14 subscriber documents and the unique IMSI index.

Host inventories and private recovery evidence remain outside this repository. Final revision-32 acceptance did not repeat end-to-end radio attachment and data-session tests.
